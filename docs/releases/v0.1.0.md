# v0.1.0 - Laravel News CRUD com Action Pattern

Primeira release do projeto de estudo Laravel News CRUD.

## Destaques

- CRUD de notícias usando Action Pattern
- Controllers finos e regras de negócio em `app/Actions/News`
- Form Requests para validação
- Upload de imagem com Laravel Storage
- Slug automático e único
- Factory, Seeder e Migration da entidade `News`
- Telas Blade com Tailwind CSS
- Busca por título, filtro por status e paginação
- Pre-commit hook com Pint, PHPStan e PHPUnit
- Commitlint com Conventional Commits
- GitHub Actions para `main` e `dev`
- Makefile com comandos de qualidade
- Testes E2E com Playwright para fluxo de notícias

## Qualidade

Checks locais esperados antes de abrir PR:

```bash
make check
```

Testes E2E:

```bash
npm run e2e
```

Modo interativo do Playwright:

```bash
npx playwright test --ui
```
